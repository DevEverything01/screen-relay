# Relay

Relay streams a Linux desktop to a browser and lets people and agents control it from a CLI and a Node SDK. See [README.md](README.md) and [docs/](docs/) for how it works.

## Writing

Use the `technical-writer` skill (`.agents/skills/technical-writer/SKILL.md`) whenever you write or edit prose for this repo. That covers the docs in `docs/`, `README.md`, the agent skills that `relay skills` serves from `skills/`, CLI help and error text, commit messages, PR descriptions, and issues.

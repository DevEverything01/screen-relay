title: Wayland
description: Start a headless sway desktop or attach relay to the compositor you run.
---

On Wayland you can either let relay start a headless sway desktop, or attach it to a compositor you already run.

```sh
./install.sh --backend wayland
export PATH="$HOME/.local/bin:$PATH"
relay up -d --backend wayland
```

`--backend wayland` installs the Wayland backend with sway, XWayland, and foot. Use `--backend all` to install X11 too. Prerequisites are in [Getting started](/docs/getting-started).

## Compositors

| Compositor | Status |
| --- | --- |
| sway, labwc | Tested |
| Hyprland (including Omarchy), river, wayfire, niri | Not tested; expected to work |
| GNOME, KDE | Not supported |

The compositor must provide `wlr-screencopy` version 3 with XRGB8888 or ARGB8888 shared-memory frames, the virtual keyboard protocol, and virtual pointer version 2. See [Troubleshooting](/docs/troubleshooting#engine-exits-with-a-missing-wayland-protocol) if one is missing.

## Start a Wayland desktop

Without `--display`, `relay up` starts headless sway with XWayland and foot, and needs no GPU. The output uses `display.resolution` from your config, 1280x720 by default. Add `--desktop none` to skip foot. To open the viewer, follow [Getting started](/docs/getting-started#3-open-the-viewer).

## Attach to your desktop

Run these commands from a terminal in your compositor session. Relay connects through the session's `XDG_RUNTIME_DIR` and captures the output at its current size.

List the outputs and note the name: `swaymsg -t get_outputs` on sway, or `hyprctl monitors` on Hyprland. Then start relay with that name:

```sh
relay up -d --backend wayland --display "$WAYLAND_DISPLAY" --output OUTPUT
```

Replace `OUTPUT` with the name you found, such as `relay` on Hyprland or `HEADLESS-1` on sway. Omit `--output` to capture the first output. `--output` works only on Wayland; with x11, `relay up` fails.

If the output is outside the [size limits](#limits), create a headless output of a supported size, then attach to it:

```sh
hyprctl output create headless relay
hyprctl monitors
```

On sway, run `swaymsg create_output` and then `swaymsg -t get_outputs`. A headless output is a separate screen, so move a window or workspace to it before it appears in the viewer.

## Limits

- Output width must be 320 to 1920 pixels and height 240 to 1080 pixels. Both must be even.
- Selecting an output by name requires `wl_output` version 4.
- The output size is fixed for the session. Restart relay to change it.
- The cursor image is not streamed. The viewer shows its own arrow.

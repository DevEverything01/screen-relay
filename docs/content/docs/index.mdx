Relay streams a Linux desktop to your browser. You open a link to see the screen and use it with your mouse and keyboard. A program, such as an AI agent, can take screenshots and send clicks, keys, and text to the same desktop from the `relay` command line, a Node SDK, or an HTTP and WebSocket API.

Relay runs the desktop on a Linux VM, container, or sandbox. It is for operators who want to use that desktop from a browser, and for agent builders who need a program to control graphical apps.

## Quickstart

On the VM, from a clone of the repository:

```sh
./install.sh
export PATH="$HOME/.local/bin:$PATH"
relay up
```

`relay up` starts the display, the desktop, and the engine that streams the screen, then prints a viewer link. Open the link in a browser with H.264 WebCodecs, such as current Chrome, Edge, or Safari. Without `-d`, `up` stays in the foreground and Ctrl+C stops the session.

## Limits

| Area | Limit |
| --- | --- |
| Display server | X11 or Wayland. `relay up` uses X11 when the engine includes it, otherwise Wayland. See [Wayland](/docs/wayland) for compositor requirements. |
| Resolution | Up to 1920x1080, set in the config ([Configuration](/docs/configuration)). A change applies when the session starts. |
| Control | One input owner at a time: a viewer or one agent. Screenshots work at any time. |
| Not supported | Audio, clipboard, IME, relative pointer, and hardware encoding. |
| Auth | One shared token per session; a session on loopback has none. No separate user identities. |
| Install | The engine installs on Linux only. Automatic dependencies cover Debian, Ubuntu, Fedora, Arch Linux, and Alpine. `--client-only` installs the CLI on any OS with Node 26 or newer. |

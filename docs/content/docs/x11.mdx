---
title: X11
description: Start an X11 desktop or attach to an existing display.
---

X11 is screen-relay's default display server. screen-relay starts a virtual X display with the XFCE desktop, on every distribution it installs on. screen-relay calls this the backend: choose it with `--backend x11`.

## Install

Install the CLI as described in [Getting started](/docs/getting-started#install-screen-relay), then set up X11:

```sh
npm install -g screen-relay
screen-relay install --backend x11
```

Setup installs the X11 packages and XFCE, then builds the engine. To set up both backends, run `screen-relay install --backend all`. Adding a backend keeps the ones the engine already has.

## Start a desktop

```sh
screen-relay up -d --backend x11
```

screen-relay starts XFCE by default. Use `--desktop none` to start without a desktop, or `--desktop COMMAND` to start another command. The display uses `display.resolution` from your [configuration](/docs/configuration), or `1280x720` by default.

To open the viewer, follow [Getting started](/docs/getting-started#open-the-viewer).

## Attach to an existing display

```sh
screen-relay up -d --backend x11 --display :0
```

Replace `:0` with your display number. screen-relay inherits `XAUTHORITY` from your environment, uses the existing display size, and starts no desktop by default. Stopping screen-relay leaves the display running.

If the engine reports `opening X display failed`, check the display number and set `XAUTHORITY` to the X session's authority file. Do not run `xhost +`.

## Check the machine

```sh
screen-relay doctor
```

If your configuration or `SCREEN_RELAY_BACKEND` selects Wayland, run `SCREEN_RELAY_BACKEND=x11 screen-relay doctor` instead. The checks cover:

- The engine, required libraries, and default port.
- `Xvfb`, `xauth`, `xprop`, `xwininfo`, `xdpyinfo`, `setxkbmap`, and required X extensions.
- XFCE, D-Bus, and icon decoding.

## Limits

- The display must be 320 to 16384 pixels wide and 240 to 16384 pixels high, with even dimensions. To resize it, change `display.resolution` and restart screen-relay. For an attached display, resize it separately before restarting screen-relay.
- `--output` is available only with [Wayland](/docs/wayland).
